# htmltest
I dette repo er de en del små webapps. Mange af dem kan køre direkte fra Github Pages. Andre ikke. De forskellige apps ligger i mapper der kmuligvis har andre apps. Kig på readme filerne i hver mappe. 

## OBS
Apps i dette repo er ikke de samme som findes i lokalhistorisk ressourcekit. Jeg overvejer om ikke apps fra ressourcekittet skal være her som en egentlig samling - så ressourcekittet er til arbejdsbrug. Der tænkes.

## Wiki
Der er også tilknyttet en wiki til dette repo - her er der en masse oplysninger - mest for mit eget brug, men du er velkommen til at kigge med.
